# ЛР 3. Библиотеки программы

Система: Windows

## Библиотеки файла
Программа напечатала: libs.exe: sqrt(2) = 1.414214
Команда для списка библиотек файла: dumpbin /nologo /dependents libs.exe | findstr /i .dll
Библиотеки libs: KERNEL32.dll (1 библиотека)
Почему в списке нет отдельной математической библиотеки: MSVC статически компонует стандартную библиотеку C (включая sqrt) прямо в libs.exe, поэтому отдельного файла для математики не видно — код уже встроен в сам exe.
Где лежит интерпретатор Python (файл или библиотека): весь интерпретатор вынесен в python314.dll (динамическая компоновка), плюс служебные api-ms-win-crt-*.dll и VCRUNTIME140.dll — в отличие от libs.exe, где C-библиотека вкомпилирована статически.
